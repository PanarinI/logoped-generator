# LogoKonspekt MVP — разбор «можем ли сейчас» (workflow-прогон)

**Дата:** 2026-08-01 · пять измерений параллельно (генерируемость · формат · флоу · стратегия · прототип). Проект: генератор листов на автоматизацию звука для логопедов; MVP на HF + 150 логопедов в ТГ; запрос эксперта Ольги (2025). См. [[project-logokonspekt]].

## Можем на 80-90% сейчас? Водораздел по единице задания
- **СЛОГ/ЛИНИЯ** (дорожки, поля-бродилки, прописи) → нужен только `{звук → слоги}` + детерминированный SVG-рендер. База слов НЕ нужна, LLM НЕ нужен, позиция звука гарантирована структурой слога. **90-95% готово сегодня, без доп. данных.**
- **СЛОВО-КАРТИНКА** (4-й лишний, зашумлённые) → нужна курируемая база ч/б клипартов с тегами `{объект→слово→звук→позиция}`. Её нет + generic-ИИ надёжно не рисует узнаваемые детские картинки. **30-55%, упирается в сбор базы (~1-2 нед), v2.**
- Ранжирование: дорожки 90-95% → прописи 80-90% → поля 75-85% (нужна разовая библиотека фонов) → зашумлённые 40-55% → 4-й лишний 30-45%.
- До MVP-2 (все 5 типов) ≈ 1.5-2.5 недели, **80% работы = база картинок, не код**. Ступень «рассказ» уже в MVP → покрыта вся прогрессия звук→слог→…→рассказ.

## Прототип (доказано делом) — файлы рядом

## ✅ МАКЕТ ВЕБАППА СОБРАН (2026-08-01, тот же день)
`logoped_webapp_mockup.html` — рабочий кликабельный прототип (self-contained, 27 КБ, без CDN). Слева форма (звук Р/Л/С · позиция · тип слогов · гласные-чипы · 1-5 дорожек · тема иконок · Дорожки|Поле), справа живое A4-превью. Кнопки: ↻ другой вариант · Скачать PNG · Печать/PDF (@media print — только лист).
Проверено: мной в браузере — оба режима рисуются, переключение мгновенное, листы качественные (кораблик→плавная РА · машинка→РО · грузовик→РУ · самолётик→петли РЫ). Агентом — 540 комбинаций параметров без исключений, 18 комбинаций слогов фонетически верны, PNG-конвейер (кириллица, canvas не tainted, ~445 КБ 2×), печать. Починен 1 баг (дубль кластера СК у звука С).
**Единственная заглушка — иконки** (векторные примитивы; в продукте → база клипартов). LLM не вызывается вообще: $0 API, мгновенно, офлайн.

**Связь с LogoKonspekt (решено):** генератор листов — ОТДЕЛЬНАЯ чистая единица, живущая РЯДОМ (та же ТГ-группа, тот же Space), НЕ пункт меню сырого конспекта. Причина: конспект требует экспертизы логопеда (потому и вышел сырым), лист — чистая параметризуемая механика (не требует). Канон: «1 app = 1 функция = 1 проблема». Ольга год назад просила «расширить» конспект — но её спецификация описывает именно самостоятельную единицу.

## Формат (канон)
- **Сейчас: HF Space** — уже live, RU без VPN, ссылка в ТГ = нулевое трение; достроить дорожки вторым режимом = «0→1 на бесплатном трафике» (`cases.md:101`).
- **Растить: standalone webapp** (свой домен/юзер/монетизация; Cloudflare-бэкенд обкатан). Деньги — lifetime $3-30 для нано-продукта (`cases.md:45,49`, fontastic).
- **Расширение — НЕ «чуждо» (натяжка снята):** технически может (как save-chatgpt-as-pdf). Просто не нужно на RU/ТГ-канале — его выигрыш = англо-Google-траст стора (`PATTERNS.md:49`), тут не работает; + установка режет конверсию (`5.4-reddit.md:52`). Позже — обёртка-лаунчер (модуль 2.6) поверх вебаппа, если захочется англо-Google. **CustomGPT отпадает** как продукт (не собирает контролируемый файл — тот самый провал generic-ИИ).

## Флоу
Desktop-web (логопед готовит за компом → печать A4). Вход: звук (Р/Л/С) · позиция · тип слогов · гласные-чипы · число дорожек · тема иконок. Выход: PDF A4. **LLM не вызывается** → мгновенное превью, $0 API, офлайн, фонетика гарантирована конструкцией. Один экран, ~6 полей, кнопка. Без аккаунтов.

## Стратегия (по методу §2.5, цитаты в прогоне)
- **Не флагман — но причина не «не твоя экспертиза»** (метод к экспертизе основателя почти безразличен — нетехнарь Rootd успешен, `cases.md:62`), а **рынок** (RU → канон меряет WTP ~0, `METHOD.md:389`, «только US/EU» `cases.md:102`) + **стадия** (WTP не измерена).
- **Prove-then-scale на 150-группе с ТОЧКОЙ РЕШЕНИЯ** (не «в никуда»): отдать вебаппом → замерить активацию/удержание → **pre-sell мелкого Pro** (`PATTERNS.md:181`). Платят → микроэкономика доказана; не платят → это ответ, не поражение; в любом исходе движок закалён.
- **Один движок логопеды↔учителя:** LogoKonspekt = первый инстанс переиспользуемого движка «структурированные задания под параметр (звук/уровень)»; де-рискует учительский флагман (US/EU, где движок метода везёт). «Чемодан без ручки» → **дешёвый полигон под флагман**.
- Риски: WTP-логопеды небогаты 🔴 · русский рынок вне SEO-движка 🔴 · зависимость от Ольги/группы 🟡 · последовательность запусков (флагман — один, `5.4-reddit.md:87`) 🔴.
