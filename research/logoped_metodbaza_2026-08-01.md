## 🔥 Схождение: первоисточник подтверждает нашу сверку 2026-08-01

**Спивак, дословно** (`Avtomatizatsia_ZVUKI_L_L_R_R.doc`):
> «АВТОМАТИЗАЦИЯ СОНОРНЫХ ЗВУКОВ / АВТОМАТИЗАЦИЯ ЗВУКА Л / 1. Спой **«песенку самолета»**: произноси звук л **длительно на одном выдохе**: л-л-л…»

Это независимо подтверждает **два** вывода canon-проверки:
1. **Метафора Л = САМОЛЁТ**, а не «плыви по волне» (наша выдумка в макете) ✅
2. **Линия дорожки кодирует ВЫДОХ** («длительно на одном выдохе»), а не нарастание сложности ✅ — ровно то, что проверка назвала главной ошибкой механики волн.

**Комарова, дословно:**
> «Автоматизация звука проводится по **традиционной в логопедии схеме**. Сначала — комплекс артикуляционной гимнастики. Затем упражнения на автоматизацию звука **изолированно, на материале слогов, слов, предложений, стихотворных и прозаических текстов**.»

Подтверждает лестницу изолированно → слоги → слова → предложения → тексты — и слова Ольги («дальше: слова, предложения итд»; «слоги — самое базовое»).

**Комарова про лабиринты:**
> «Ребёнок произносит звук «Р», **называя картинки** на странице, перемещая игрушку по лабиринту. Если слово произнесено неправильно, следующий ход задерживается до правильного произношения.»

Важно: в каноническом лабиринте ребёнок называет **КАРТИНКИ (слова)**, а не голые слоги. Наш макет генерит слоговые дорожки без картинок-слов — это упрощённая форма. Плюс механика «неправильно → ход задерживается» = встроенный контроль, которого у нас нет.

**Жихарева-Норкина** — само существование серии «Домашняя тетрадь» подтверждает находку проверки: **лист домашнего задания — реальная издаваемая единица**, а не наша догадка.

2. **Наши выводы из открытых источников совпали с закрытой базой автора** — значит canon-проверка 2026-08-01 надёжна.
3. **Набор звуков в пособиях**: С, З, Ц, Ш, Ж, Ч, Щ, Л, Ль, Р, Рь, Т, Ть, Д, Дь, М, Мь, Н, Нь — то есть свистящие+шипящие покрыты полностью (подтверждает вывод проверки, что выбор Р/Л/С в макете выбросил шипящие).

## Что НЕ извлечено
Полные тексты пособий — в векторном хранилище OpenAI (файлы `file-XXX`), локально утеряны. В `docs/file_search` только выдержки из поисковых ответов (~10 тыс. симв.). Для полноценного изучения нужны либо сами книги, либо исследование по этим авторам.

## Технические заметки по core
- Архитектура: публичная обёртка (тема+CSS) → `gr.load("zenivan/LogoKonspekt_core")` по `HF_token`.
- В core: `app/prompt.txt` (справка по структурам занятий — общая, без пособий), `app/prompt.py` (24 КБ), `app/worksheets.py` (**пустой файл — задел на рабочие листы, тот самый запрос Ольги**), `app/data/existing_files.json` (ID файлов, теги почти везде пустые — разметка не доделана), `docs/` (costs, errors, ideas, logic, mistakes), `TASKS.md`.
- В `TASKS.md` есть строка `[x] оговорка об авторских правах на пособия` — вопрос прав автором уже осознавался.
