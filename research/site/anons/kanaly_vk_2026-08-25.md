## Метод — воспроизводимо, без входа в ВК

Поиск сообществ ВК **открыт для незалогиненного**, если попасть на правильный адрес:

```
https://vk.ru/search/communities?q=<запрос>
```

- ⚠ Старый формат `?c[q]=…&c[section]=communities` открывает страницу поиска, но **запрос не
  подставляет** — отдаёт «Рекомендации» (телеканалы, рецепты). Работает только `?q=`.
- Отдаёт ровно **20 сообществ на запрос** и не догружает прокруткой. Поэтому охват набирается
  **разными запросами**, а не листанием одного.
- Со страницы сообщества видны: название, число подписчиков, статус (верифицировано /
  подтверждённый бизнес), описание, витрина товаров, блок «Контакты».
- ❌ **Стена (посты) скрыта** от незалогиненного. Значит «жив ли канал» и «что он постит»
  проверяется только из аккаунта автора. Всё, что ниже про живость — 🔶.

Запросы, давшие улов: `логопед` · `логопедические пособия` · `автоматизация звуков` ·
`материалы для логопедов`. Всего 73 уникальных сообщества, ниже — разложенные по типу.

## Главная находка: три разных типа, и один из них — ловушка

**Лавки (не писать).** Больше половины выдачи по «пособиям» — магазины: продают ровно тот товар,
который logozvuk отдаёт бесплатно. ✅ Проверено на витрине «Логоши» (`/logosha_pro`, 10 тыс.):
«Универсальные рабочие листы» 99–129 ₽, «Первый звук» 129–139 ₽, «Картотека артикуляционных
упражнений» 199 ₽, в описании прямо — «задания для автоматизации звуков», «рабочие листы для
печати». Просить лавку разместить бесплатный заменитель её товара — просить закрыть себе выручку.
Сюда же: ЛогоЛисичка, print-game, «авторские игры», LogoPro, ЛогоКубик, «Игра Звуков».

**Стены-агрегаторы (платное размещение).** Крупные сборники материалов, живут рекламой.
✅ У `/vpomlogo` статус «Подтверждённый бизнес» и рекламный номер ERID в описании — реклама у них
легальная и, значит, платная. Блока «Контакты» нет: писать только сообщением сообществу из
аккаунта.

**Логопеды-блогеры (обзор).** Живой человек с лицом, который сам ведёт занятия и показывает
инструменты. Только здесь бывает обзор, а не «репост со ссылкой».
