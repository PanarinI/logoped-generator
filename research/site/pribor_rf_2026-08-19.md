# Чем мерить поисковый спрос в России — разведка 2026-08-19

Повод: у DataForSEO нет локации «Россия» ни в одном эндпоинте (проверено вызовами 08-19:
`kw_data_google_ads_locations(RU)` → пусто, `serp_locations(RU)` → пусто, Labs `keyword_suggestions`
с location "Russia" → Invalid Field, Trends с "Russia" → Invalid Field). Значит РФ-спрос нужно
мерить другим прибором.

Расклад поиска в РФ: Яндекс ~55–65%, Google ~35–40%. Любой инструмент, меряющий только Google,
даёт меньшую половину картины. Ниже это учтено в каждой строке.

## ГЛАВНОЕ: прибор найден и уже сработал

**Букварикс (bukvarix.com) отдаёт частотность Вордстата через бесплатный API без регистрации.**
Ключ опубликован открыто: `api_key=free`. Проверено вызовами 08-19 — данные ниже реальные,
не оценка.

```
http://api.bukvarix.com/v1/keywords/?q=<фраза>&api_key=free&num=1000&format=csv
```

Возвращает: фраза · слов · символов · **широкая частотность** · **«!точная !частотность»**.

### Что этот замер говорит про веер страниц

Два вывода, и они противоположны исходной гипотезе:

1. **Спрос сидит на «автоматизация звука <буква>», а не на «рабочих листах».**
   Р / Л / Ш / С — это 1 500–4 100 точных в месяц каждый. Это ядро веера: страница на звук.
2. **Формулировки «рабочие листы» и «распечатать» в РФ почти мертвы.**
   «рабочие листы логопеда» — 2 точных. «логопедические задания распечатать» — 3.
   «задания логопеда распечатать» — 0. Это калька с английского printable worksheets,
   в русском поиске её не спрашивают. Называть страницы так — значит писать в пустоту.

Разрыв «широкая vs точная» тоже нужно читать: «автоматизация звуков» — 69 304 широкой, но 97
точной. Широкая — это сумма всего хвоста, а не спрос на саму фразу. Веер строить по точной.

## Рекомендация: одна

**Мерить первым — Буквариксом, через бесплатный API. Он уже работает и уже дал числа.**

Почему именно он:
- ноль денег, ноль регистрации, ноль ожидания — прибор включён прямо сейчас;
- это данные **Яндекса**, то есть та самая большая половина РФ-поиска, которой у DataForSEO нет;
- отдаёт **точную** частотность, а не только широкую — без этого веер строился бы на мираже
  (см. «автоматизация звуков»: 69 304 широкой против 97 точной);
- есть отдельная база **«Яндекс Россия»** — прямая замена отсутствующей у DFS локации.

### Что должен сделать автор

1. **Ничего — для первого прохода.** Замер выше уже сделан, веер можно строить на нём:
   страницы по звукам (Р, Л, Ш, С, Ж, З), а не по «рабочим листам».
2. **Войти в Wordstat под своим Яндекс-аккаунтом** (wordstat.yandex.ru, вход бесплатный) и
   сверить 5–6 верхних фраз с регионом «Россия». Это калибровка: Букварикс — снимок октября 2025
   по региону «весь мир», Wordstat — живые числа по РФ. Коэффициент между ними закрывает
   обе дыры разом, дальше можно снова мерить дёшево Буквариксом и домножать.
3. **Если понадобится массовый добор с регионами** — Мутаген, 30 ₽ за 100 проверок, без подписки.
   Дешевле любой абонентки.

## Граница знания — что НЕ измерено

- **Google-половина РФ-спроса не измерена вообще.** Букварикс и Вордстат — данные Яндекса.
  Для ~35–40% рынка чисел нет: DFS не даёт локацию Russia, Google Trends даёт только 0–100.
- **Числа Букварикса — по региону «Весь мир»**, не по РФ. Туда входят Беларусь, Казахстан,
  русскоязычная диаспора. РФ-доля будет ниже — насколько, покажет только сверка с Wordstat.
- **Данные — снимок 14.10.2025**, не живые. На 08-2026 им ~10 месяцев. Сезонность
  логопедической ниши (сентябрь — пик учебного года) в этом снимке не видна.
- **Соответствие Букварикс ↔ Wordstat не откалибровано.** Коэффициента пока нет — в отличие от
  DataForSEO, где калибровка сделана (объём ×1.5, KD 0.84·DFS+26).
- **Конкуренция и сложность выдачи не мерены** — только объём спроса. Кто уже занимает эти
  запросы, неизвестно.
- **WB/Ozon как прокси не проверены** — публичный эндпоинт WB с не-РФ IP отдаёт усечённый ответ.
- **Тарифы Keys.so, Rush, Топвизора, Пиксель Тулс, Serpstat взяты из обзоров, не с их
  прайс-страниц** (страницы рендерятся JS). 🔶 непроверено, порядок величины.
